# Familienhub themes

Ready-made themes for [Familienhub](https://github.com/Brottuetchen/familienhub). Every theme has a light and a dark variant.

## Install

In the app: **More → Appearance → From GitHub** (admins), then paste the link of a theme from the table. The theme is then available to everyone in the family.

| Theme | Style | Link to paste |
|---|---|---|
| **Candy Pop** | Bright pink and sky blue, very round cards with hard shadows, pastel gradient. | `https://github.com/Brottuetchen/familienhub-themes/blob/main/candy-pop/theme.json` |
| **Cyberpunk** | Neon yellow and cyan on near-black, hard edges, terminal fonts. | `https://github.com/Brottuetchen/familienhub-themes/blob/main/cyberpunk/theme.json` |
| **E-Ink Reader** | Calm greyscale like an e-reader, list layout, minimal borders. | `https://github.com/Brottuetchen/familienhub-themes/blob/main/e-ink-reader/theme.json` |
| **8-Bit Gameboy** | Four greens of the original handheld; dark variant as a green phosphor terminal. Pixel titles. | `https://github.com/Brottuetchen/familienhub-themes/blob/main/gameboy-pocket/theme.json` |
| **Matcha Zen** | Soft greens and latte tones, glass cards with a gentle glow. | `https://github.com/Brottuetchen/familienhub-themes/blob/main/matcha-latte/theme.json` |
| **Nordic Fjord** | Glacier blue and violet glow, glass cards. | `https://github.com/Brottuetchen/familienhub-themes/blob/main/nordic-fjord/theme.json` |
| **Midnight OLED** | True black for OLED screens with emerald and indigo accents; light variant included. | `https://github.com/Brottuetchen/familienhub-themes/blob/main/pitch-black-oled/theme.json` |
| **Retro Synthwave** | Hot pink and cyan on deep purple, 80s neon glow. | `https://github.com/Brottuetchen/familienhub-themes/blob/main/retro-synthwave/theme.json` |
| **Solarized Paper** | Warm paper tones with forest green and brown, round cards. | `https://github.com/Brottuetchen/familienhub-themes/blob/main/solarized-paper/theme.json` |
| **Swiss Bauhaus** | Bauhaus/Swiss style: red, navy and yellow, square cards, heavy uppercase titles. | `https://github.com/Brottuetchen/familienhub-themes/blob/main/swiss-grid/theme.json` |

## Make your own

A theme is one `theme.json` with colours and a few style switches, no code. Format and rules: [docs/themes.md](https://github.com/Brottuetchen/familienhub/blob/main/docs/themes.md). Pull requests with new themes are welcome; please add a folder with `theme.json` and a line in this table.
